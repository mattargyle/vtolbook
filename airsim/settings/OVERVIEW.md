# airsim/settings — Overview

AirSim client configuration.

## Files

- `settings.json` — copied (or symlinked) into `~/Documents/AirSim/` before
  launching AirSim. Defines the vehicle type, camera placement, and other
  AirSim-side parameters used by the non-ROVIO scripts in this package.

The ROVIO experiments use a different `settings.json` that lives in
`../rovio/`.
