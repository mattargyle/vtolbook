# splines — Overview

Scratch directory for B-spline experiments referenced from the trajectory
planning material.

## Contents

- `bspline_basis.py` — plots uniform and uniform-clamped B-spline basis
  functions for various degrees using `scipy.interpolate.BSpline`. Standalone
  script: run it directly to pop matplotlib figures.

A more developed splines workspace lives at
`textbook/chap5_trajectory_planning/splines/` (including
`collision_avoidance/`); this directory is the lightweight playground.
